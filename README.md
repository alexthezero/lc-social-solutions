# L C Social Solutions

Mock one-page website for L C Social Solutions, a small business social media design and strategy brand.

## Files

- `index.html` — site structure and page content
- `style.css` — leafy green, neutral, off-white visual styling
- `script.js` — mobile navigation, scroll reveal animation, and demo contact form behavior

## GitHub Pages

After the files are committed, enable GitHub Pages:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Go to **Pages**.
4. Under **Build and deployment**, set source to **Deploy from a branch**.
5. Choose branch **main** and folder **/root**.
6. Save.

The site should publish at:

`https://alexthezero.github.io/lc-social-solutions/`
